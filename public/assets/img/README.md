# Folder Aset Logo & Gambar Bersama

Folder ini (`public/assets/img/`) digunakan untuk menyimpan gambar global / bersama aplikasi NutriMate sesuai dengan panduan rules.md:

- `logo.svg` atau `logo.png` : Logo utama NutriMate (dipakai di navbar, sidebar, dan footer).
- `hero.svg` atau `hero.png` / `hero.jpg` : Gambar banner hero meal prep untuk halaman home / landing page.
- Subfolder:
  - `landingPage/` : Aset khusus halaman depan / landing page.
  - `foods/` : Gambar katalog menu makanan.
